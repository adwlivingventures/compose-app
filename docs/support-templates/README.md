# Compose Support Templates

Source-of-truth replies for the support inbox. Every reply inherits the CLAUDE.md rules:
calm, non-judgmental, grounded, premium tone; **no refund promises or refund language**
(point to Apple's process, nothing else); **no medical claims** (we never diagnose, treat,
or promise outcomes); **no discussing any individual's app use with anyone but that user**.

Practical rules:

1. Reply from a dedicated address (set up support@ on your domain — do not reply from a
   personal Gmail). Sign every reply "— Compose Support". Never use the user's full name
   in the subject line; assume shared inboxes exist.
2. Personalize the first sentence, keep the template body, never stack templates —
   one issue per reply.
3. If a message contains both an emotional issue and a billing issue, answer the
   emotional one first.
4. Never argue with an angry user, never defend in public reviews with specifics —
   the discretion rules apply to us too.
